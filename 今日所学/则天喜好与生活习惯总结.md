## 二、饮食偏好

### ✅ 喜欢吃的

**火锅 / 涮**
- 锅底最喜欢 **番茄锅**，其次菌汤、三鲜；不吃辣，不要香菜、葱、蒜。
- 酱料碟分两个：
  1. 麻酱 + 花生碎 + 醋 + 芝麻
  2. 两勺醋 + 一勺丸滑酱油（解腻好吃）
- 料碗会放**芝麻和花生**，多放点；放点醋再加点汤汁/酱油稀释酸味。
- 火锅和烧烤隔一段时间吃一次。
- 也喜欢**海底捞金汤花椒鸡锅底**。

**主食**
- 米饭三种吃法：**蛋炒饭、拌饭、烧麦**。
- 喜欢吃比较**细的面**和**龙须面**（细面 ≈ 我喜欢的牛肉面族系）；说面时说「龙须面 / 圆挂面 / 宽挂面」来区分。
- 喜欢吃**烙饼**，用饼卷菜吃，有时加点酱。
- 糯米/水果玉米都吃，**更喜欢黄色的糯玉米**。

**口味 / 调料**
- 喜欢吃**番茄酱**，涉及番茄的都可以接受，**饺子蘸番茄酱**。
- 喜欢**抹茶**口味，喜欢吃**甜品**。
- 贝果、米面包、碱水球这类**不甜的面包算非甜品类**，不属于甜品。
- 喜欢**肉松**（煎饼、卷凉皮里加肉松和小辣条）；喜欢**锅包肉**。

**水果（喜欢）**
- 尤其喜欢**水蜜桃**；常吃蓝莓、香蕉、樱桃、梨。
- 桃子买**半红半白的硬桃子**更好。
- 柚子（红柚、白柚都可）；凤梨（凤梨头不扎手，菠萝扎手、孔深）。
- 青椒/水果彩椒（不辣的那种）、菠菜（补铁）。

**饮料**
- 喜欢**咖啡**，现在喜欢买饮料自己调咖啡；**柠C美式和苹果美式并列第一**。
- 做咖啡用稍粗的粉风味更好，比例大概 **2:1**；新配方：气泡水 + 冰块 + 咖啡 + 饮料（冰块要多才压得住气泡水的气）；瑞幸葡萄冰萃（NFC葡萄果汁 + 葡萄泥 + 冰块）。
- 椰子水喝 **if 牌**；可乐喝 **百事（崂山）**，不喝可口可乐（太甜），百事树莓味/草莓味更好。
- **牛乳绿豆沙** 更受喜欢。
- 喝**低糖不甜的**饮料；酸奶+燕麦脆、水果+酸奶（像水果捞）都好吃。

**零食**
- **大屋酸奶**（银桥益生菌发酵乳，大盒的是大屋，小盒不划算一般不买）。
- 各种**不很甜的**面包、**瑞幸各种小甜品**、蟹棒、小鸡腿、苹果干、乐事薯片。
- **好利来抹茶小饼干、玫瑰花饼**。
- **燕麦脆**（尤其胖东来的）；椰子脆片、凤梨夹心肠（购买比例可多点）。
- **火山石烤肠**（一次一两根就够，隔几天做一次）；**牛肉干买辣的**可以吃。
- 面包放冰箱要敞开口放，不然有水珠。

### ❌ 不喜欢 / 忌口

**调料类**
- **生葱、生蒜、生洋葱、香菜、韭菜**（前四个味道大，韭菜难消化）。
- **生蒜苔**（半生不熟辣），炒熟透了会吃一点；**蒜和姜怎么吃都辣**，不怎么吃。
- 不吃**很辣的**，偶尔带一点辣椒可以吃；基本不吃辣（觉得辣难以品尝食物原味）。
- **不吃熟的调料**，但不介意炒菜放——做菜时用葱等起味的，把调料煸入味后**提前取出来**。
- 芹菜不要；虾不要。

**水果（忌口）**
- **芭乐**（籽少或集中的可以吃）、**石榴**（我不买必须吃那种）、**菠萝少吃**、**无花果少吃**（吃多蛰舌头）、**甘蔗不吃**。
- **葡萄尽量不吃，提子可以**；之前吃过的长条葡萄是蓝宝石葡萄。
- **软桃不吃**（太甜）。
- **隔夜的西瓜不吃**（细菌繁殖太快）。

**饮料**
- **甜甜腻腻的酸乳饮料**不喝（真果粒、AD钙等）；可以喝低糖不甜的。
- 少喝**热的酸饮料**（会导致反酸、消化不了）。
- 抹茶不点热的（会腻）。

**其他**
- 711 的牛肉干不好吃、不买；瑞幸**焦糖海盐甜品太甜**，进黑名单。
- 不吃太多**冰的、凉的、寒性**的东西，对身体不好。
- **苦瓜等降压的**少吃；少熬夜。
- 生理期附近食欲把握不准，可能什么都想吃，也可能高油高糖就不喜欢。

## 三、生理期全攻略

### 饮食
- 不能吃**冰的、凉的、寒性**食物，辣的食物也不行（一点点辣、少许冰块可少吃，有度）。
- 水果选**补气血/中性补充能量**：樱桃、水蜜桃、香蕉、桂圆、橙子。
- 吃**猪肝、牛肉、鸡腿**等补铁补能量；生理期前买点肉食（袋装鸡腿、猪肝）。
- 生理期附近**喜欢吃面包甜品**，快到的时候买点；冬天胃不舒服喝**生姜可乐 / 生姜红茶**。

### 用品（卫生巾 vs 棉条）
- 卫生巾和棉条**都用**；**棉条 > 卫生巾**（卫生巾不舒服、夏天热易滋生细菌）。棉条出去玩/运动时用，方便；在实验室用卫生巾是因为囤多了。
- 棉条 2–3 小时换；如果一小时内拉粑粑也会换（蹲下不得劲、绳子可能脏）。棉条开口处怕做工不精细划伤；之前外国品牌头部一头大一头小扯出来不舒服就不用了。
- 用量（正常量，均码/约100斤）：开始 **护垫+棉条**；中间2–5天 **日用250mm左右**；快结束**护垫+棉条**；晚上用**安睡裤**（不穿内裤）。
- 月经判断：内裤湿湿的、有痕迹。
- 女性阴道和尿道不在一起，用棉条也能正常上厕所。

### 照顾要点
- **提前一周提醒**（按一个月一算，例如5月6日 → 6月6日，5月31日提醒）。
- 出去拿水杯就大概率喝杯里的热水，不买外边饮料 → 及时补热水。
- **每2.5–3小时提醒上厕所**。
- 生理期**不运动**，散散步就行；低强度散步促进血液循环、改善痛经情绪，但过度运动会子宫收缩剧烈、经血变多。
- 生理期可能**拉肚子、痛经**；一天拉四五次就该吃药；则天基本不吃药，除非很严重（脱水等）。
- 可以少量吃**鱼油**缓解痛经、改善情绪。
- **备点止痛药**（布洛芬 / 对乙酰氨基酚片）以防万一，原理是抑制前列腺素；则天微痛不用药。
- 穿**三角内裤**方便（四角的会窝着卫生巾）。
- 不舒服的核心来源：**休息不好、熬夜、压力、作息不规律** → 多陪伴缓解压力、规律作息、补充维生素水果，不惹则天生气。
- 生理期前**乳房会涨、疼**。

## 四、身体与健康

- **体寒**，不能被空调直吹；可接受热一点，但要避免很凉。空调风调到合适位置（风向左、对墙吹小风）。
- 睡不够会**脑子痛**；睡眠不好会引发**双眼皮肿**。
- 锻炼后**肩宽不能侧睡**（会落枕），锻炼当天睡前提醒不侧睡。
- **颈椎**有时不舒服，多活动活动（电梯间少看手机、摇头晃脑）。
- 晕车：坐车少看手机，听播客/脱口秀；晕车贴易掉（内裤腰低），**多用晕车药**。
- **早上不吃会低血糖**，提醒早上吃东西。
- 舌头有**裂舌**比较敏感（刷牙会疼、菠萝芭乐扎舌头）。
- 皮肤是**中性皮**。
- 晚上六七点后不喝水；饭后不喝水（涨肚）；吃饭不能太晚（肚子饱睡不着）。
- 在家带耳塞久了耳朵不舒服，可换**头戴耳机**（非游戏耳机，实验室带游戏耳机怪怪的）。
- 半夜会把胳膊伸出来冻没知觉，要**掖被子**；一起住时不怎么开空调。
- 在家带**耳塞**；打羽毛球（找凉快场馆/不热时）。
- 脱毛6次后可能不长（冰点激光破坏毛囊）。
- 适度吃坚果（一周50–70g），万事有度。

## 五、生活习惯

### 出门在外
- **不喜欢坐公共场合座位**（如地铁）；公园椅子要垫**坐垫**；出门备坐垫；任何要坐的时候都用坐垫。
- 出门用**酒精湿巾**（酒店、公共场合触摸后给则天擦手；公共都是细菌）。
- **提前一天确认第二天出门要拿的东西**。
- 牵手时拉着小宝手在前面；坐车看她喜欢安静享受两人时光，想讲就小声讲。
- 出门带纸巾；贴驱蚊贴或穿长袖（防蚊）。
- 出去带水杯 → 及时补热水。
- 好宝楼里**11点就不能洗澡**，出去玩早点回来。

### 在家
- 睡觉**穿睡衣**；习惯穿睡衣。外衣不能上床；外面回来洗手、最好换家居服；饭前洗手。
- 空闲时喜欢**打扫干净、整整齐齐**，有**生活秩序感**；喜欢**断舍离**（麻烦用处不大的直接扔）。
- 喜欢自己做美食：以后有家，**咖啡机、烤箱、空气炸锅、揉面机是标配**；会把家里整理得有条理；周内忙会提前备好食材（生的配好两人量，熟食冷冻开化加热）。
- 未来房子打算**全屋智能装修**。
- 马桶要买**带加热**的（不然屁股凉）。
- 会买很多**可爱的东西**放家里，温馨；最可爱的是小强。

### 物品 / 用具
- 喜欢**有口或吸管的杯子**，要有提绳或斜跨绳（拿着方便）；容量**500ml左右，不超800ml**；水杯温度**40多度**合适；杯子不要太慢（拧盖子会渗水）；水杯不放键盘前、不放桌面放地上/旁边。
- 书包有两个：一个花花软软的、一个登山稍硬的。

### 其他
- 喜欢**小摩托车**；电车充电「2个电」要充（载人易欠压），用完拍照好找。
- 洗水果去枝去叶（桃子、苹果、梨、草莓、樱桃）；果切要切好洗干净。
- 分东西不要说「剩一个正好给你」（像凑数），要说「正好还有三个，咱们一人一个」。
- 出去时和朋友的**消息要回**（朋友有事/没事找都要回）。
- 喜欢先品尝再慢慢吃（面包、饮料），吃饱了就不吃；只针对给则天买的。
- 衣服**深色浅色分开洗**；晾衣服前甩甩防皱；洗衣机胶圈脏了擦一下。
- 买特价水果要仔细看（可能有坏的）。
- 则天**不喜欢黄色**的东西（不和则天搭配）。

## 六、穿着 / 化妆 / 护肤

- **口红：YSL 314**。
- 皮肤**中性皮**；**粉质化妆品不易变质**。
- 化妆流程（淡妆）：**青蛙王子牛奶保湿霜 → 防晒霜 → 遮瑕 → 粉底液 → 定妆粉 → 眼影腮红 → 口红**；更麻烦的还会再加。
- **腮红**：浅色是**膨胀色**（涂眼睛下面，也可作亮片/眼影），深色是**收缩色**（涂颧骨脸颊）。
- **洗头皂**：何首乌侧伯叶；**护发素**：资生堂小红帽；**护发精油**：且初。洗头皂洗发根、护发素护发中和发梢，**洗两次**。
- **卸妆膏**：以油融油，揉化涂脸后用温水洗。
- 内衣：夏天穿轻薄一点的；能束胸、无凸点即可；3/4样式包裹性好但不太透气；**全纯棉支撑力不够**；吊带可带胸垫。轻微**咪肌分离**是锻炼练上胸所致，没影响。
- 有妆时**亲亲脸要干亲、蜻蜓点水**（不唑脸）。
- 有很多**卷发棒**（不同形状），**玉米夹**让头发蓬松。
- 三个睡衣：白色棉的、小熊的、上下分开的。
- 则天给我买**较多浅色衣服**（显皮肤好、阳光）。

## 八、沟通与相处方式（核心）

### 关于"我"如何做
- **积极主动交流**，寻找平衡，不压自己的想法；不好的地方会主动说出来。
- **减少反问**（说者无意听者有心）；**多多解释、多多说**。
- 不说「不行」，用「**不要**」+ **原因**（则天不喜欢只听不行，要带上为什么）。
- **完全表露心声和情绪**；则天不是全知，不可能完全知道我的想法 → 多多表露心意。
- **不堆积作业**：事情当时就说，能白天说的不留到晚上（则天睡觉很轻，晚上开导耗心力影响第二天）；主动说情绪有**奖励（小心愿）**，堆积有**惩罚**。
- 回消息**先回正在想的**，培养思考过程；及时回，**不超3小时**；回不了一件事相关说一段，不引用跳来跳去。
- 除了十万火急的事，**不听坏坏和小B的**，第一时间和则天讲自己的情绪一起处理；坏坏、小B、小强的话都给则天说。
- 自己的事情**没完成前**，除则天消息外其他人都先等一下（急事打电话解决）。
- 想不明白的东西，随时和则天讨论或记下来当面聊（理论深度思考的喜欢当面说，看则天说；急事立马说）。
- 遇事把自己的想法和解决方法说出来，相关则天的事听则天说心里话再折中。
- 遇争议**认真说清、商量解释，不指责**；两个人是一条心的。
- 打错字、上厕所不检查，**罚5块和亲亲**。
- 出门兜里一直带纸巾。
- 以后**对自己做好事记录/任务**，则天布置的任务认真完成；科研和亲亲挂钩是则天姐姐的鞭策。

### 尊重与边界
- **尊重则天的个体性和自己的个体性**；人和人不一样，不强求，不控制。
- 则天有自己的人际处理方式，在她说之前**不插手**把事情变糟；被冒犯且则天反击时再插手。
- **不插手指责别人**；除亲近的人外，不插手别人的命运和想法。
- 则天**最烦理所当然的坏毛病**；不喜欢看不到别人付出的人。
- 则天有**异性友谊很正常**，不控制，有想法温柔交流或撒娇（很少）。

### 三个很难拒绝的事（免死金牌，只用于哄则天爱护身体）
1. 小强喊则天**姐姐**
2. 「**我想**」这个词

## 九、人生看法与价值观（则天与我的共同观念）

- 则天有**五年计划**，拆开实现，制造动力和期待。
- **人生意义**：按自己喜欢的方式过完这一生（合理合法、不损他人、遵守规则前提下），不按别人想法活着而后自怨自艾。
- **爱**：论心也论迹；迹会随时间变化，靠沟通说明。爱**不是被证明，而是被表达**，发自内心的爱才是好的。
- **喜欢 vs 爱**：喜欢/心动是即刻瞬间的多巴胺；持续的喜欢才是爱，两者互相渗透。
- **只要爱的缔结**，其他都是形式，坚不可摧。
- **不生孩子**（对女性身体损伤大、未知性多），喜欢小孩但想享受两人生活；对父母慢慢做思想工作。
- 消费观：**该省省该花花**，有券就用；不买溢价产品；买东西不是为了回报，而是**分享的喜悦**。

- 当**不刻意寻找时就会拥有**（爱情、身材、形象管理、化妆…）：有目标但不强求，做好当下一步步来。
- 人**要平衡发展**（不堪的一面、理性一面、好的一面都是真实自己），重视情绪和感受，拥抱内在小孩。
- 因果循环，种下的因得相应的果，细心留意才注意到。
- 学习是**辅助生活**的，以生活为主干建知识大树；读书批判性阅读，精而不多。
- 认知和心态提升的过程不舒服，有人陪着引导就不会难受——两人一起相互扶着向前走。
